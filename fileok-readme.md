# FileOK preview

FileOK is an upload-problem fixer rather than a generic toolbox.

## MVP
- Parse common upload requirements from error text
- Inspect JPG, PNG and WebP locally in the browser
- Convert output format
- Resize to exact pixel dimensions
- Compress toward a maximum KB target
- Verify the generated output against the selected requirements

## Business direction
Search landing pages should focus on problems such as files being rejected, exact KB limits, exact dimensions, and incompatible image formats. Monetization should not interrupt the core fix flow. Potential channels: contextual ads on landing pages, a paid batch mode later, and verified requirement presets for high-intent application workflows.

No user files are sent to a processing backend in this MVP.
